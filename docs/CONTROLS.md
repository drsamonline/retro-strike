All bindings can be reached from the in-game **Settings** menu where noted.

## Keyboard & Mouse

| Action | Key |
|---|---|
| Move forward / back | `W` / `S` |
| Strafe left / right | `A` / `D` |
| Turn | `←` `→`, `Q` `E`, or **mouse** |
| Fire | `Space` or **left mouse** |
| Sprint | `Shift` *(drains stamina)* |
| Select weapon | `1` Blaster · `2` Spread · `3` Rifle · `4` Beam |
| Cycle weapon | `X` |
| Throw grenade | `G` |
| Drop mine | `B` |
| Throw cluster | `H` |
| Cycle throwable type | `T` |
| Melee | `V` |
| Dash | `C` |
| Pause / menu | `Esc` or `P` |
| Mute toggle | `M` |
| Photo mode | Pause → **Photo Mode** |
| Shop list | `Tab` *(during intermission)* |
| Buy shop item | `1`–`0` *(during intermission)* |
| Menu navigation | `↑` `↓` + `Enter`; `Esc` to go back |
| Title: change difficulty / new arena | `D` / `N` |

> ⌨️ An **AZERTY (ZQSD)** preset is available in Settings → Keyboard.

## Touch

- **Move** — left virtual joystick. Push to the edge to sprint.
- **Aim / turn** — drag anywhere on the right side.
- **FIRE** — the large round button, bottom-right.
- **SWAP** — cycle weapon.
- **NADE** — tap to throw; **long-press to cycle** grenade / mine / cluster.
- **DASH**, **MEL** — dash and melee.
- **⛶** — enter fullscreen (locks landscape where supported).
- In **Photo Mode**, tap the top of the screen to exit.

Portrait phones show a **rotate-to-landscape** hint (tap to play anyway).
Layout options: **Big Buttons**, **Left-handed**, **Large HUD**.

## Gamepad

| Action | Button |
|---|---|
| Move | Left stick |
| Turn | Right stick |
| Fire | RT (`7`) or RB (`5`) |
| Cycle weapon | LB (`4`) |
| Throw | X (`2`) |
| Pause | Start (`9`) |
| Menu navigate | D-pad up/down (`14`/`15`) |
| Menu confirm / back | A (`0`) / B (`1`) |
